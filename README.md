# Mini Katalog Uygulaması

## Kısa Açıklama:
Bu proje, Flutter temel eğitimi kapsamında geliştirilmiş başlangıç seviyesinde bir mobil katalog uygulaması taslağıdır. Uygulama içerisinde ana sayfa ürün ızgarası (`gridView`), ürün detay sayfası, sayfa arası geçişler (`Navigator`) ve temel sepet simülasyonu yer almaktadır.

---

## Kullanılan Teknolojiler ve Ortam:

- **Flutter Sürümü:** 3.50.0 (Stable Channel)

- **Geliştirme Ortamı:** Visual Studio Code

- **Kullanılan Paketler:** Yalnızca varsayılan `material.dart` kütüphanesi (Harici paket kullanılmamıştır)

## Proje Klasör Yapısı:

- `lib/`
    - `main.dart`: Ana uygulama, ürün listesi, detay sayfası ve sepet state yönetimini barındırır.
- `test/`: Otomatik test dosyaları.

---

## Çalıştırma Adımları:
Projeyi yerel ortamınızda çalıştırmak için terminalde sırasıyla şu adımları izleyin:

1. Terminali veya komut satırını açın.

2. Projenizin ana klasörüne gidin (Terminalde `cd mini_katalog` yazıp Enter tuşuna basın).

3. Paketlerin yüklenmesi veya güncellenmesi için şu komutu yazıp Enter tuşuna basın: `flutter pub get`

4. Uygulamayı başlatmak için şu komutu yazıp Enter tuşuna basın: `flutter run`
